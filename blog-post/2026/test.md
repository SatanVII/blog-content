# 《做 VLOG 三年，我总结的全流程心得》总结

> **一句话总结**：这是一份从“前期策划—执行拍摄—设备选择—后期剪辑—心态建议”的全流程 VLOG 干货，核心观点是：**表面松弛的镜头，背后全是心机和巧思；先拍先剪，做才有答案。**

**关键词**：`前期策划`、`A-roll/B-roll`、`拍摄设备`、`后期剪辑`、`声音设计`

---

## 一、前期策划：从攻略到风格

前期策划分为两个阶段：

| 阶段 | 重点 | 说明 |
| --- | --- | --- |
| 第一阶段 | 提供内容 | 收集整理基础客观事实，偏攻略向：怎么去、多少钱、景点渊源、路线安排 |
| 第二阶段 | 找到风格和喜好 | 带着主观视角拍摄，形成自己的风格；风格来自人生阅历、音乐、书、路、喜欢的博主和见过的世界 |

- 攻略向内容已经饱和，但整理过程能带来安全感。
- 创作者不是“人形 GoPro”，一定要有主观视角和看法。
- 一条视频不可能满足所有观众，不必讨好所有人。
- 选择自己的视角，做自己，吸引同频的人。

**团队协作**：
- 团队加上博主共 5 人。
- 前期由博主和编导同学 **彩虹** 配合。
- 博主提供方向，编导整理内容，博主再找合适视角发散。
- 资料整理推荐 **飞书**，支持手机、电脑、Pad 多平台多人线上编辑。
- 对于众说纷纭的信息，建议多问几个 AI 进行考证。

## 二、执行拍摄：行程、天气与镜头规划

出行每天都在花钱，所以合理规划行程和拍摄窗口非常重要。

### 1. 拍摄要考虑的因素

- 天气
- 光照
- 潮汐
- 日出日落

### 2. 实用工具推荐

| 工具 | 用途 |
| --- | --- |
| `WENDY` | 精确定位云图、降雨量、风速，部分区域可调用当地摄像头 |
| `skyline` | 不出门看世界各地实时风景 |
| `卢米` | 精准定位日出日落，抓住 golden hour |
| `LUMOS` | 测量每天每小时太阳位置，安排拍摄内容 |

### 3. A-roll 与 B-roll

- **A-roll**：决定拍摄下限，好的故事哪怕用掏耳勺拍也精彩。
- **B-roll**：提升质感和上限。
- 超长行程要提前规划：
  - 哪几天是 A-roll 拍摄日
  - 哪几天是 B-roll 拍摄日
  - 哪几天是坏天气、垃圾时间，直接用来赶路

### 4. 路线制定

- 摄影师、制片、编导四方辩论。
- 吵完架后，往往能得到路线最优解，也最具性价比。
- 短途出行也可以举一反三：
  - 早上五点拍日出
  - 九点动物园开门拍 A-roll
  - 夜晚安排夜钓等

## 三、拍摄设备：长期主义与三镜头法

### 1. 主力设备

- 索尼 **FX3**
- 索尼 **ZV-E1**
- 镜头：大三元
- 无人机：`Mavic 4 Pro`
- `POCKET` 作为辅助镜头补充

选择 FX3 和 ZV-E1 的原因：
- 拥有同样的 CMOS，方便后期调色统一管理。
- FX3 轻便微单里的 T1 队列。
- ZV-E1 轻便、性价比高，适合延时和手持录制 A-roll。

### 2. 镜头推荐

- 以往使用大三元系列。
- 推荐 **F2.0 28-70**，索尼超三元系列。
- 917 克，手持和稳定器友好。
- F2.0 大光圈变焦，相当于拥有定焦画质的变焦镜头。
- 拥有缩放齐焦功能，提升拍摄效率。
- 对拍视频来说，最重要的是 **对焦** 和 **轻便**。

### 3. 补充设备

- 索尼 **DV**：复古，拍出来“活人感满满”。

### 4. 三镜头法

| 镜头 | 内容 |
| --- | --- |
| 镜头一 | 自拍，记录客观事实或抒发情感 |
| 镜头二 | 把镜头当成眼睛，记录看到什么、想记录什么、什么有感受 |
| 镜头三 | 把自己放回环境里 |

> 三步执行下来，就是一组相对完整的镜头组，能最大程度保留当下信息，方便未来剪辑做故事串联和镜头选择。

## 四、后期流程：Final Cut Pro + 达芬奇

### 1. 软件选择

- 现在使用 **Final Cut Pro** 剪辑。
- 导出 XML 再进入 **达芬奇** 调色。
- 工作室、本地大屏多人办公：推荐 `team` 方式，剪辑调色全部在达芬奇里进行。
- 个人 VLOG、笔记本小屏剪辑：推荐 Final Cut Pro。
  - 面板少
  - 操作简单
  - 好上手
  - 14 寸笔记本剪辑不难受

### 2. 剪辑流程

- 博主先把素材和一个文档给剪辑同学 **小霸王**。
- 文档写清：
  - 本期想表达的主题
  - 哪些素材重点保留
  - 哪些地方可以删除
- 剪辑同学整理原始素材，剔除无关内容——也就是 **切菜**。
- 博主拿切好的原料，再进行文案、配音、音乐等——也就是 **炒菜**。

### 3. 声音与音乐

- 声音设计对片子影响非常大，会增强生动感和代入感。
- 音乐没有捷径：**多听、多积累**。
- 听过的音乐类型足够多，才知道什么战斗拿什么兵器。
- 推荐多看电影原片。
- 对博主影响很大的导演是 **昆汀**：
  - 电影里有大量神来一笔的音乐
  - 看似没关系，放到故事里却超级和谐
  - 还帮助叙事
- 所有大师都从模仿开始，可以先找到自己喜欢的导演风格，从学习和模仿开始。

### 4. 推荐博主

- **百万剪辑师**：直播剪辑视频受益良多。
- **风过大泽**：拉片博主，讲得非常细，推荐看完原片后再看拉片。
